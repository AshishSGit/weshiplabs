## THIS WEEK (Days 2-7)

### Step 4: Find 10 businesses to Loom audit
Where to find them:
- Google "[your city] + [industry]" (restaurants, dentists, realtors, gyms)
- Product Hunt — new startups with rough products
- LinkedIn — search "looking for developer" or "need an app built"
- Reddit r/startups, r/smallbusiness — people asking for help

For each business:
1. Visit their website or app
2. Find ONE specific problem (slow load, broken mobile, no contact form, ugly design, manual process that could be automated)
3. Screenshot or screen-record the problem

### Step 5: Record 10 Loom videos (90 seconds each)
Script:
```
"Hey [name], I was looking at [their site/product] and noticed [specific problem].

For example, [show the problem on screen — slow load, broken mobile layout, etc].

This is probably costing you [customers/time/money] because [reason].

There are a few ways to fix this — happy to share if you're interested.

Either way, hope this is useful. Have a great day."
```
No selling. No mention of your services. Just value.

### Step 6: Send 10 emails

## WEEK 3-4

### Step 11: Close your first client
By now you should have:
- 3-4 replies from Loom outreach
- 1-2 referrals from personal network
- 3 free audit conversations

When someone says "I'm interested":
```
1. Ask: "What are you trying to build and when do you need it?"
2. Listen. Don't talk about yourself.
3. Say: "Got it. I'll send you a one-page quote by tomorrow."
4. Send a simple quote:
   - What we'll build (3-5 bullet points)
   - Timeline (X weeks)
   - Fixed price ($X)
   - What's included (30 days support, deployment, etc.)
   - "Reply 'go' to start this week."
```

Keep it short. No 20-page proposals. One page, fixed price, clear scope.

### Step 12: Start the project
1. Get 50% upfront, 50% on delivery
2. Send weekly updates with a staging link
3. Deliver on time
4. Ask for a testimonial
5. Add the case study to weshiplabs.com
